The reader wants to understand a mechanism, not copy code.
- Two sentences at most: the mechanism in plain words.
- show_steps with 2-4 short steps when it is a sequence (a turn, a card answered); no code blocks in the steps unless one is essential.
- show_pages: the concept page with the diagram.
