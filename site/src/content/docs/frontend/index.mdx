## Frameworks

| Framework | Today | How |
| --- | --- | --- |
| **React** | supported | `<AguiChat>` from `@formguide/agui-chat/react`; `useFormguide` from `@formguide/agui-chat/react-hook-form` for react-hook-form and Formik |
| **Any page** (server-rendered, Vue, Angular, Svelte, none) | works | `<agui-chat>` is a standard Web Component: one script tag, set `chat.options` and `chat.use(formguide({...}))` from your code |
| **Angular** | coming | a module with an `<agui-chat>` component, inputs and outputs, and a form-control bridge |
| **Vue** | coming | a component and a `useFormguide` composable |
| **Svelte** | coming | a component and a store bridge |

Your form does not need React either: the form skeleton is JSX-like text that any backend can produce ([Works with any framework](connect-your-form/#works-with-any-framework)). The server does not change with the framework: every client speaks the same [AG-UI contract](connect-your-form/contract/).

## What every client does

<ArchFigure page="integrate" />

1. **Register the form's skeleton once**: `POST /agent/layouts {jsx, form_id}` → `jsx_hash`.
2. **Send the form with every message** in AG-UI `state`: `{config, jsx_hash, form_id, ui}`.
3. **Draw what comes back**: streamed text, "look here" directives, cards.
4. **Answer a card** after applying accepted values through your form backend; the agent continues with the new config.

The chat widget's form plugin does 2 to 4 for you: you give it `getState()` and `applyChanges()`. Every message as a TypeScript type: [Types and the contract](connect-your-form/contract/).
