## How to use it

1. **Change a setting on the left.** The chat on the right changes at once. The sections go from big to small: the layout (bubble, side panel, inline, page, hero), colours and theme presets, shape, component tokens, CSS for any part, cards, your own components, icons.
2. **Talk to it.** The chat is connected to the demo agent, so you see your settings in a real conversation. The card buttons show every card without waiting for the agent to send one.
3. **Open Code and copy.** You get your settings as HTML, as React or as a theme, with the lines you changed highlighted. Paste it into your page.
