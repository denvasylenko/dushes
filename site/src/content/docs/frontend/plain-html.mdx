`<agui-chat>` is a Web Component with no runtime dependencies (about 40 KB gzipped as one script, English built in), so it works on any page: server-rendered templates, Vue, Angular, or none at all.

```html
<agui-chat url="/agent/run" title="Assistant"></agui-chat>
<script src="agui-chat.iife.js"></script>
<script>
  const chat = document.querySelector('agui-chat')
  chat.use(AguiChat.formguide({
    getState: () => ({ config: window.formConfig, jsx_hash: window.jsxHash, form_id: 'loan_application' }),
    applyChanges: async (changes) => {
      const r = await fetch('/form/event', { method: 'POST', body: JSON.stringify({ changes }) })
      return (window.formConfig = await r.json())
    },
  }))
</script>
```

The script defines the element and `window.AguiChat` (`AguiChat.formguide`, `AguiChat.h`, `AguiChat.defineTheme`, `AguiChat.addLanguage`). Without the plugin it is a chat for any AG-UI endpoint.

Serve the whole `dist` folder: next to `agui-chat.iife.js` lie `agui-chat.lang-ru.js`, `-uk`, `-de`, `-fr`, `-it`, `-es`, and the chat adds the one for its language when it needs it (a few KB; English needs none).

## Floating, inline or full page

| `mode` | Looks like |
| --- | --- |
| `floating` (default) | a round button in the corner that opens a side panel |
| `inline` | fills its box: put it in a sidebar or a column next to the form |
| `page` | the whole window |
| `hero` | a landing's big field alone; the first message grows it into the chat in place (a full-screen sheet on a phone). `chat.send(text)` sends a preset, `chat.setPlaceholder(text)` changes the hint, `agui:open` / `agui:close` tell the page |
