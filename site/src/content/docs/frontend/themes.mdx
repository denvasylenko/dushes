## Themes

```js
import { defineTheme } from '@formguide/agui-chat'      // the one-script build: AguiChat.defineTheme

defineTheme('acme', {
  tokens: { accent: '#0a7f6f', radius: '10px', font: '"Inter", sans-serif' },  // both schemes
  light: { link: '#0a7f6f' },
  dark: { accent: '#4fd1c1', 'on-accent': '#06201d', bg: '#0f1514', surface: '#151d1c' },
  css: '.chip { font-weight: 600 }',                                           // scoped to the widget
})
```

```html
<agui-chat theme="acme" scheme="auto"></agui-chat>
```

Or `chat.options = { theme: 'acme' }`, `<AguiChat theme="acme" />`, or an object right away: `chat.options = { theme: { tokens: { radius: '0' } } }`.

- Token keys may drop the prefix: `accent`, `--accent` and `--agui-accent` are the same. An unknown key, or a value containing `;`, `{` or `}`, is ignored with a console warning.
- `extends: 'contrast'` starts from another theme (default: `default`).
- Built in: `default` (the standard look). Four more ship as packs the chat loads the first time a page uses one (a few hundred bytes each; English pages with the default theme download none):

| Theme | Looks like |
| --- | --- |
| `glass` | translucent frosted cards over a soft gradient, blue accent and bubbles, large radii, in the spirit of iOS |
| `bold` | large radii, strong type and a vivid blue on clean cards; in dark, glassy cards over a deep glow, in the spirit of a fintech app |
| `messenger` | bubbles for both sides on a wallpaper, a light blue accent, in the spirit of a messenger |
| `contrast` | pure black and white, stronger lines and text, a thicker focus ring, for accessibility |

`<agui-chat theme="glass">` is all it takes; with a bundler each pack is its own chunk, with the one-script build the chat adds `agui-chat.theme-<name>.js` from next to `agui-chat.iife.js`. `extends: 'glass'` builds your theme on one (load it first with `await loadTheme('glass')`). Try them all in the [Playground](../playground/).

Frosted glass on any theme is one token: a translucent `card-bg` plus `card-blur`:

```js
defineTheme('frost', { extends: 'default', light: { 'card-bg': 'rgba(255,255,255,.6)', 'log-bg': 'linear-gradient(160deg,#eef3ff,#fdf3ee)' },
  tokens: { 'card-blur': 'blur(24px) saturate(180%)' } })
```
- A theme can be defined after the element appears: elements that use its name switch to it at once. Until then, and for an unknown name, the default theme is used.
- `themes()` lists the registered names.

## Tokens on the element

For one page, CSS is enough. The element reflects `data-scheme="light|dark"` and `data-theme`, so you can target one scheme:

```css
agui-chat { --agui-accent: #0a7f6f; --agui-panel-width: 520px; }
agui-chat[data-scheme="dark"] { --agui-accent: #4fd1c1; }
```

Avoid setting colours with `style.setProperty` on the element: inline values apply to both schemes. Use a theme or a `data-scheme` rule instead.

| Token | What it colours or shapes |
| --- | --- |
| `accent`, `on-accent` | primary buttons, the floating button, the logo, and the text on them |
| `link` | links and the focus ring |
| `bg`, `surface`, `soft` | the panel, cards and the composer, quiet fills (code, user bubbles) |
| `ink`, `ink-2`, `ink-3` | text: main, secondary, hints |
| `line`, `line-2` | dividers and borders |
| `ok`, `on-ok`, `danger`, `on-danger` | success marks, errors, the recording mic, and the text on them |
| `shadow`, `scrim` | the shadow colour of the panel and the floating button; the backdrop behind the floating panel |
| `radius`, `radius-sm`, `radius-lg`, `radius-pill` | cards and the inline frame; buttons, inputs and the logo; the composer and bubbles; chips, round buttons |
| `font`, `panel-width`, `ease` | the font stack, the floating panel's width, the motion curve |

Each is `--agui-<name>` in CSS.

## Parts: every element has a name

Every element the chat draws has a `part`: the header, each message, every card piece (questions, rows, options, calendar days, steppers, review rows, receipts), the composer. Style any of them from the page with `::part()`, or inside a theme's `css` with `[part~="..."]`. These names are the stable API; the widget's class names are internal and may change.

```css
agui-chat::part(card) { border-width: 2px; }
agui-chat::part(option) { border-radius: 0; }
agui-chat::part(calendar-day-selected) { background: #0a7f6f; }
agui-chat::part(button-primary) { text-transform: uppercase; }
```

```js
defineTheme('square', { css: '[part~="chip"], [part~="option"], [part~="button"] { border-radius: 4px; }' })
```

Cards also carry `card-<type>` (`card-set_fields`, `card-ask`, `card-review`, ...). All names: `panel`, `scrim`, `fab`, `header`, `logo`, `title`, `subtitle`, `icon-button`, `close`, `log`, `empty`, `empty-title`, `empty-intro`, `message`, `user`, `assistant`, `message-body`, `steps`, `steps-toggle`, `step`, `suggestions`, `typing`, `notice`, `error`, `composer`, `composer-box`, `input`, `send`, `mic`, `attach`, `attachments`, `hint`, `chip`, `action-chip`, `chip-selected`, `button`, `button-primary`, `button-secondary`, `button-link`, `button-danger`, `actions`, `result`, `tag`, `text-input`, `number`, `number-stepper`, `number-step`, `select`, `editor`, `card-question`, `card-title`, `card-message`, `row`, `row-label`, `row-value`, `row-tools`, `row-previous`, `row-issue`, `card-reason`, `document`, `fold`, `option`, `options`, `comparison`, `comparison-column`, `search`, `day-strip`, `slots`, `range`, `slider`, `range-preview`, `stepper`, `fields`, `fields-item`, `date-field`, `calendar`, `calendar-title`, `calendar-nav`, `calendar-weekday`, `calendar-day`, `calendar-day-selected`, `calendar-today`, `calendar-cell`, `review`, `review-section`, `review-issue`, `sources`, `source`, `receipt`, `feedback`, `details`, `consequence`, `dropzone`, `progress`, `privacy`.

## Component tokens

Each component reads its own tokens first, falling back to the global ones, so you can change one kind of element without touching the rest. They work as CSS variables on the element and as short keys in a theme.

| Component | Tokens |
| --- | --- |
| panel, header, log | `panel-bg`, `panel-ink`, `header-bg`, `header-ink`, `header-border`, `log-bg` |
| messages | `bubble-user-bg`, `bubble-user-ink`, `bubble-ai-ink`, `bubble-radius` |
| cards | `card-bg`, `card-ink`, `card-border`, `card-radius`, `card-padding` |
| buttons | `button-bg`, `button-ink`, `button-radius`, `button-secondary-bg`, `button-secondary-ink`, `button-secondary-border` |
| chips and options | `chip-bg`, `chip-ink`, `chip-border`, `chip-radius`, `chip-on-bg`, `chip-on-ink`, `option-bg`, `option-ink`, `option-border`, `option-radius` |
| inputs | `input-bg`, `input-ink`, `input-border`, `input-radius`, `input-height` |
| composer | `composer-bg`, `composer-border`, `composer-radius`, `composer-area-bg` |
| calendar | `calendar-on-bg`, `calendar-on-ink` |
| bubble mode | `bubble-width` (400px), `bubble-height` (680px), `bubble-offset` (20px), `bubble-window-radius` (24px), `launcher-size` (60px) |

```js
defineTheme('acme', { tokens: { 'card-bg': '#f7faf9', 'card-radius': '18px', 'bubble-user-bg': '#0a7f6f', 'bubble-user-ink': '#fff' } })
```

## Icons

Replace any built-in icon with an SVG string or an element: `logo` (header and floating button), `send`, `stop`, `mic`, `clip`, `plus`, `close`.

```js
chat.options = { icons: { logo: '<svg viewBox="0 0 24 24">...</svg>', send: mySendIcon } }
```

## Your own components (slots)

`render` puts your own element in place of any piece; return nothing to keep the default for that case. A slot that throws falls back to the default with one console warning.

| Slot | Gets | Replaces |
| --- | --- | --- |
| `markdown(text, chat)` | the answer text | the answer's HTML, also while it streams (return an HTML string) |
| `assistant(text, chat)` | the finished answer | the answer bubble's content (also restored answers) |
| `user(text, files, chat)` | the message | the user bubble's content |
| `empty({title, intro, starters}, chat)` | | the empty chat |
| `header({title, subtitle, newChat, close}, chat)` | | the header |
| `error({message, kind, text, retry}, chat)` | the failure | the error line and its Try again |
| `suggestions(items, chat)` | quick replies | the chips under the answer |
| `launcher({open, unread}, chat)` | | the bubble's launcher content (an avatar, a brand mark); the click, the unread dot and the open state stay the widget's |
| `sources(items, chat)` | `{title, section, quote}[]` | the source chips (formguide plugin) |
| `composer(chat)` | | the whole composer; call `chat.send(text)` |

Cards are replaced the same way through the renderer registry (`chat.renderers.set('ask', myCard)`, see [Cards and answers](../cards/)), and their building blocks are exported from `@formguide/agui-chat/formguide` for your own cards: `calendar`, `dateField`, `timeGrid`, `schemaForm`.

With the system setting "reduce motion", nothing animates.

The widget renders in a shadow root, so your page's CSS does not leak in and its CSS does not leak out. There are three layers, and each one overrides the one before:

1. the widget's defaults;
2. a **theme**: tokens for both schemes, per-scheme overrides and optional CSS inside the widget;
3. **your page's CSS** on `agui-chat` (tokens and `::part()`).
