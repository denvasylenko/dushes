Or do it yourself, below. The steps set up the **form assistant**, the base of both. For a **whole site**, do the backend steps, then add [Dushes](../../agents/site-agent/) on top: a site map and one more router.

## Backend

<Steps>

1. **Install and scaffold.**

   ```bash
   pip install "formguide[all] @ git+https://github.com/denvasylenko/dushes.git#subdirectory=backend"
   formguide init my-agent          # formguide.yaml, domain_packs/my_form.json, skills/example_skill/
   ```

2. **Pick a model.** It is the only required setting.

   <Tabs syncKey="provider">
     <TabItem label="Anthropic">
       ```yaml title="my-agent/formguide.yaml"
       model: "anthropic:claude-haiku-5-5"
       ```
     </TabItem>
     <TabItem label="OpenAI">
       ```yaml title="my-agent/formguide.yaml"
       model: "openai:gpt-5"
       ```
     </TabItem>
     <TabItem label="Azure OpenAI">
       ```yaml title="my-agent/formguide.yaml"
       models:
         agent: {class: "langchain_openai:AzureChatOpenAI", azure_deployment: gpt-5, api_version: "2025-04-01-preview",
                 azure_endpoint: "${AZURE_OPENAI_ENDPOINT}", api_key: "${AZURE_OPENAI_API_KEY}"}
       ```
     </TabItem>
   </Tabs>

3. **Check and serve.**

   ```bash
   formguide check --config my-agent/formguide.yaml          # no model calls; names a missing key
   ANTHROPIC_API_KEY=... formguide serve --config my-agent/formguide.yaml --cors "*"
   ```

   The agent is at `POST http://localhost:8000/agent/run`.

</Steps>

## The page

One HTML file: a small form, the chat, and the two functions that connect them. Save it as `index.html`, or [download it](../../examples/quickstart.html).

<Code code={example} lang="html" title="index.html" />

Serve the folder and open it:

```bash
python3 -m http.server 8080      # then open http://localhost:8080
```

Ask "Where do I start?" The agent reads the form, points at fields and proposes values on a card; accept it and the fields fill in.

What the file does, in its three numbered parts:

1. **The layout, once.** Your form's elements and how they nest, as JSX-like text (no React). The server keeps it and returns its id, `jsx_hash`.
2. **The form as it is now.** `config` is `{props, state}`: each element's settings and each field's value. The chat sends it with every message.
3. **Accepted values.** When the user accepts a card, `apply` puts the values in your form and returns the new `config`.

<Aside type="note" title="Where the chat script comes from">The widget is not on npm yet. To try it, the file loads the copy this site serves. For your app, build it from the repository: `cd packages/agui-chat && npm install && npm run build` puts `agui-chat.iife.js` in `dist/`.</Aside>

More on each part: [Connect your form](../../frontend/connect-your-form/); every key of `config`: [Send the form each run](../../frontend/connect-your-form/state/); React, react-hook-form and others: [Choose a client](../../frontend/).

<Aside type="caution">The endpoints authenticate nobody: see [Deploy and secure](../../agents/shared/deploy/) before going live.</Aside>
