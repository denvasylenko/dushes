| | The model's history | The transcript |
| --- | --- | --- |
| Holds | messages, tool calls, the compacted memory | the bubbles, cards and answers the user saw |
| Store | any LangGraph checkpointer | any `TranscriptStore` |
| Default | in memory (lost on restart) | files under `<data_dir>/transcripts` |
| Compacted in long chats | yes | never |

```yaml title="formguide.yaml"
checkpointer: {sqlite: data/checkpoints.sqlite}   # needs the sqlite extra
transcripts: {dir: data/transcripts}              # or: memory
```

## Restore a chat after a reload

```ts
const r = await fetch(`/agent/threads/${threadId}?format=agui&form_id=loan_application`)
const { messages, pending_card, starters } = await r.json()
agent.setMessages(messages)            // a pending card comes back too
```

`<agui-chat>` does this by itself when `persist-thread` is on (the default). `DELETE /agent/threads/{id}` forgets a conversation.
