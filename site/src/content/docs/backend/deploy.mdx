## Before it faces the internet

<Steps>

1. **Auth in front.** Mount the router behind your own dependency, or a gateway. A thread id is the only key to a conversation.

   ```python
   app.include_router(create_router(guide), prefix="/agent", dependencies=[Depends(require_user)])
   ```

2. **Protect the manager endpoints** harder than the chat: `/kb/*` changes what the agent tells every user.

3. **CORS** to your origins only: `create_app(..., cors=["https://my.app"])` or `formguide serve --cors https://my.app`.

4. **Rate limiting** per user at the gateway: every message is a model call.

5. **Never `debug=True` in production**: `GET /debug/{thread_id}` shows the model's history to anyone with the id.

</Steps>

## What to keep on disk

`data_dir` holds learned field dependencies, registered layouts, documents, attachments and transcripts. Mount it as a volume, or point each store elsewhere (a SQL checkpointer, your own transcript store, a vector store).

## Container

```dockerfile title="Dockerfile"
FROM python:3.12-slim
WORKDIR /app
RUN pip install "formguide[all] @ git+https://github.com/denvasylenko/dushes.git#subdirectory=backend"
COPY formguide.yaml ./
COPY domain_packs/ ./domain_packs/
COPY skills/ ./skills/
ENV FORMGUIDE_CONFIG=/app/formguide.yaml
VOLUME /app/data
CMD ["formguide", "serve", "--host", "0.0.0.0", "--port", "8000", "--cors", "https://my.app"]
```

```bash
docker run -p 8000:8000 -e ANTHROPIC_API_KEY=... -v formguide-data:/app/data my/formguide
```

<Aside>Behind a proxy, turn off response buffering for `/agent/run` (it streams server-sent events). The server already sends `X-Accel-Buffering: no` for nginx.</Aside>
