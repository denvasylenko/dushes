Each recipe is a folder under `backend/demo/recipes/` with its `formguide.yaml` and any tool code. QA's scenarios run that same folder, so the page shows the files that were measured, and how often the expected thing happened.

```bash
cp -r backend/demo/recipes/confirm-side-effect my-agent
cd my-agent && PYTHONPATH=. ANTHROPIC_API_KEY=... formguide serve --config formguide.yaml   # PYTHONPATH: the tool module sits here
```
