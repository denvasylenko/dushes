## Read and forget a conversation

Two endpoints serve the transcript, so a client can show the chat again after a reload:

```bash
curl "http://localhost:8000/agent/threads/t1?format=agui&form_id=loan_application"   # messages, pending_card, starters
curl -X DELETE http://localhost:8000/agent/threads/t1                                  # transcript + model history
```

`format=agui` returns AG-UI messages; without it you get the raw transcript entries. A card the user had not answered comes back as `pending_card`.

## A reload does not lose the answer

A turn runs on the server as a background task, apart from the response that streams it. When the user closes the tab or reloads mid-answer (or a phone unloads the page), the turn still finishes and records its answer and card in the transcript. While it runs, `GET /threads/{id}` says `running: true`; the widget shows "Still working…" and checks back every 2 seconds until the result is there. A new message for that thread waits for the running turn (up to 120 s). Since a closed connection no longer ends the turn, the chat's Stop calls the stop endpoint:

```bash
curl -X POST http://localhost:8000/agent/stop -H 'Content-Type: application/json' -d '{"thread_id": "t1"}'   # {"stopped": true}
```

Without the router, `guide.run_detached(...)` gives the same: stream it, and the turn outlives the stream; `guide.running(thread_id)` and `guide.stop(thread_id)` go with it. Running turns live in the server process: restarting it ends them. A host with its own server can do better than "Still working…": return `follow` from the plugin's `restore` (a function giving the turn's events again, from its start) and the chat plays them live, so the answer goes on word by word. The page side of this is one attribute on the widget: [restore after a reload](../../../frontend/widget/#restore-after-a-reload).

## Every option

```yaml title="formguide.yaml"
data_dir: data                                   # transcripts default to data/transcripts
checkpointer: {sqlite: data/checkpoints.sqlite}  # default: in memory; Postgres and Redis in Python
transcripts: {dir: data/transcripts}             # or: memory
memory:
  max_history_tokens: 60000                      # compact the model's history above this
  keep_turns: 4                                  # recent user turns kept word for word
  model: "anthropic:claude-haiku-5-5"            # the summarizer; default: the research model
```
```python title="app.py"
from formguide import GuideConfig, FileTranscriptStore, MemoryTranscriptStore, sqlite_checkpointer
from formguide.config import MemoryConfig

GuideConfig(
    checkpointer=sqlite_checkpointer("data/checkpoints.sqlite"),   # any LangGraph BaseCheckpointSaver
    transcripts=FileTranscriptStore("data/transcripts"),            # or MemoryTranscriptStore(), or yours
    memory=MemoryConfig(max_history_tokens=60_000, keep_turns=4, model="anthropic:claude-haiku-5-5"),
)
```
