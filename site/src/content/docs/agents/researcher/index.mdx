## The pattern

The researcher runs apart from the conversation. An agent hands it one question; it searches and reads as many sections as it needs, with read-only access, and gives back a short answer with the sections it came from. The long reading never enters the chat's context, so the conversation stays small and fast. The chat shows each source as a chip under the answer.

## When the agents call it, and when not

| Question | Who answers |
| --- | --- |
| what a field means, a rule of the form, what the site offers | the agent itself: domain knowledge is compiled into the core's knowledge, which every agent sees |
| a detail deep in a policy, a price list or the terms | the researcher, through the agent's `ask_documents` action |

Both agents have the action: the UI agent (`FormGuide`) on a screen with documents, and the site agent (Dushes) on any page (`Dushes.ask_documents`, which calls the same `knowledge.research`). Each reads only the documents its knowledge scope allows.

## Switch it on

```bash
pip install "formguide[research]"      # included in formguide[all]
```

```yaml title="formguide.yaml"
models:
  research: "anthropic:claude-sonnet-5-5"       # the researcher; default: the agent model
actions:
  ask_documents: auto                           # auto: only when there are documents; true | false
knowledge:
  scopes: {loan_application: [loan_application, bank_common]}   # which documents each form may read
```
