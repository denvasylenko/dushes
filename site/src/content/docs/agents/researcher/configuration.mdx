## Switch it on

```bash
pip install "formguide[research]"      # included in formguide[all]
```

## Settings

```yaml title="formguide.yaml"
models:
  research: "anthropic:claude-sonnet-5-5"       # the researcher; default: the agent model
actions:
  ask_documents: auto                           # auto: only when there are documents; true | false
knowledge:
  scopes: {loan_application: [loan_application, bank_common]}   # which documents each form may read
```

| Key | Default | What it does |
| --- | --- | --- |
| `models.research` | the agent model | the model the researcher reads with; it needs tool calling |
| `actions.ask_documents` | `auto` | whether the agents get the action: `auto` only when the form has documents, `true`, `false` |
| `knowledge.scopes` | each form reads its own namespace | which document namespaces a form may read |

Every key with its default: [Configuration keys](../../../reference/configuration/).
