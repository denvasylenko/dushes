## Building a guide

- `load_config(path)`: reads `formguide.yaml` into a `GuideConfig` (unknown keys fail with their name)
- `GuideConfig(...)`: the same in code: models, domain packs, knowledge, skills, tools, stores, memory, `interrupt_mode`
- `FormGuide(config)`: the guide: the agent graph and everything it needs
- `formguide.server.create_router(guide, debug=False)`: the router for your own app ([HTTP API](../http-api/))

<ParamList kind="function" signature="formguide.app.create_app(config=None, *, prefix='/agent', cors=None, debug=False, static_dir=None)" id="create-app">
  <Param name="config" type="GuideConfig | FormGuide | str | Path | None" default="None" id="create-app-config">A config, a ready guide, or the path of a `formguide.yaml`.</Param>
  <Param name="prefix" type="str" default="'/agent'">Where the agent's routes are mounted.</Param>
  <Param name="cors" type="list[str] | None" default="None">Allowed origins for a page on another host.</Param>
  <Param name="debug" type="bool" default="False" id="create-app-debug">Adds `GET /debug/{thread_id}`, which shows the model's history: development only.</Param>
  <Param name="static_dir" type="str | Path | None" default="None">A folder of static files served at the root, e.g. your built page.</Param>
  <Fragment slot="returns">A FastAPI app.</Fragment>
</ParamList>

## Dushes: the assistant for a whole site

```python
from formguide.site import Dushes, SiteMap, create_dushes_router
```

- `SiteMap.load(path or dict)`: the site map: pages with `path`, `title`, `description`, `keywords`, `form`, `tabs`, `accordions`, `sections`
- `Dushes(form_guide, site_map, model=None, ...)`: the site assistant above your `FormGuide`; `model` defaults to the form guide's agent model. Keyword options: `knowledge_namespaces`, `router_model`, `context`, `instructions`, `style`, `history`, `tools`, `suggestions`, `form_for` ([Site agent](../../agents/site-agent/))
- `create_dushes_router(dushes, host=None)`: its FastAPI router ([HTTP API](../http-api/#dushes-the-site-assistant)); `host(request)` builds your object for every run
- `SiteGuide`, `create_site_router`: the old names, kept as aliases

### run

<ParamList kind="async method" signature="FormGuide.run(thread_id, *, message=None, state=None, resume=None, run_id=None, client_tools=None, tool_results=None, prefill=None, capabilities=None, trace_context=None, reply_to=None)" id="run">
  <Param name="thread_id" type="str" required id="run-thread-id">The conversation.</Param>
  <Param name="message" type="str | None" default="None">The user's new message.</Param>
  <Param name="state" type="dict | None" default="None">The form now: `{config, jsx_hash, form_id, ui?, attachments?}`. Sent with a new message, after frontend tools and with prefill.</Param>
  <Param name="resume" type="dict | None" default="None">The answer to the card the last turn showed. A field-change card: `{accepted, config?, ui?, names?, comment?}`; a question: `{answer: {ids?, text?}}` (`{accepted: False}` skips); an upload request: `{attachment_ids}`; a confirmation: `{accepted}`.</Param>
  <Param name="run_id" type="str | None" default="None">Your id for this turn; a new one when omitted.</Param>

  <Param name="trace_context" type="dict[str, str] | None" default="None">The caller's W3C trace headers `{traceparent, tracestate}`; with OpenTelemetry on, the turn joins that trace.</Param>

### conversations

<ParamList kind="method" signature="FormGuide.conversations(since, until=None, *, merge=True)" id="conversations">
  <Param name="since" type="datetime" required id="conversations-since">The window's start, included. An aware datetime; a naive one is read as UTC.</Param>
  <Param name="until" type="datetime | None" default="None" id="conversations-until">The window's end, excluded; `None` is now.</Param>
  <Param name="merge" type="bool" default="True" id="conversations-merge">Fold a form's own thread under Dushes (`"<thread>-<form_id>"`) into its site thread; every entry of a merged conversation then carries `agent`: `"site"` or `"form"`. A thread on its own has no `agent` on its entries.</Param>
  <Fragment slot="returns">A generator of `{thread_id, entries}`: each conversation where something was said in `[since, until)`, with only that window's entries, in time order. It needs a transcript store with `threads()` ([Persistence](../../agents/shared/persistence/#your-own-store)).</Fragment>
</ParamList>

```python
from datetime import datetime, timedelta, timezone

since = datetime.now(timezone.utc) - timedelta(days=1)
for c in guide.conversations(since):
    print(c["thread_id"], len(c["entries"]))
```

### purge

<ParamList kind="async method" signature="FormGuide.purge(older_than_days, *, dry_run=False)" id="purge">
  <Param name="older_than_days" type="float" required id="purge-older-than-days">Delete every conversation whose last entry is older than this many days (its `ts`, not the file's time).</Param>
  <Param name="dry_run" type="bool" default="False" id="purge-dry-run">Only count, delete nothing.</Param>
  <Fragment slot="returns">`int`: how many conversations were deleted (or would be). Each goes whole: the transcript, the model's history (checkpoint) and the attachments. It works without the package's server, e.g. from a nightly job.</Fragment>
</ParamList>

```python
n = await guide.purge(30, dry_run=True)   # how many are older than 30 days
await guide.purge(30)
```

### Conversations, documents and attachments

| Method | Does |
| --- | --- |
| `thread(thread_id, form_id=None)` | the display transcript, the pending card and whether a turn is still running |
| `thread_messages(thread_id)` | the transcript as AG-UI messages |
| `async delete_thread(thread_id)` | forget a conversation: its transcript, the model's history and its attachments |
| `add_document(namespace, filename, data)` / `delete_document(namespace, doc_id)` | manage business documents |
| `async compile_knowledge(form_id, jsx, config)` | compile the documents in the form's scope into its domain pack |
| `save_attachment(thread_id, filename, data)` | store a user document for the next run |
| `async history(thread_id)` / `recent_runs(thread_id)` | the model's history and recent run stats, for debugging |
| `stop(thread_id)` | stop the thread's running turn (the chat's Stop); `True` when one was running |
| `running(thread_id)` | whether a turn is running for the thread |
| `feedback(thread_id, value, card_id=None)` | keep a thumbs rating (`1` or `-1`) from the chat in the thread's transcript |
| `warm_up()` | load what the first request would wait for (the Whisper model) in the background; `create_app` calls it, call it yourself when you mount the router |

Every key of `GuideConfig` and its YAML form: [Configuration keys](../configuration/#every-key).
