## Button

One **filled** button per view: the main action. **Gray** for secondary actions, **plain** for a text link, **quiet** for toolbars (a fill on hover). Three heights: 32, 36, 44 px; every one is 44 px on a touch screen. An `href` makes it a link.

  <Button variant="plain" href="#button">Open in Claude</Button>
  <Button variant="quiet" size="sm">Start over</Button>
  <Button variant="quiet" iconOnly icon="sidebar" aria-label="Hide the sidebar" />
  <Button variant="gray" disabled>Disabled</Button>
</Specimen>

## Copy button

Copies, then says **Copied** with a check for a moment. With `target` it copies that element's text; inside a code panel it copies the panel's code; a script that builds the text calls `copyText(button, text)` (it may be async, like Copy page).

<Specimen>
  <CopyButton target="#ds-copy-src" />

  <CopyButton variant="filled" size="lg" label="Copy prompt" target="#ds-copy-src" />
  <code id="ds-copy-src">npm i @formguide/agui-chat</code>
</Specimen>

```astro
<CopyButton target="#install" />

<script>
  import { copyText } from '../components/ui/ui'
  button.addEventListener('click', () => copyText(button, () => buildPrompt()))
</script>
```

## Chips

One choice among a few short options: a radio group, so arrow keys move the choice and Tab leaves the group. The group fires `ui-change` with the value. A chip can also be a link (`<a class="ui-chip">`) for a row of jump links.

<Specimen layout="col">
  <ChipGroup label="Your app" options={[['widget', 'Any page'], ['react', 'React'], ['rhf', 'react-hook-form'], ['copilotkit', 'CopilotKit']]} value="react" />
  <div class="ui-chips"><a class="ui-chip" href="#chips">Questions</a><a class="ui-chip" href="#chips">Field changes</a><a class="ui-chip" href="#chips">Documents</a></div>
</Specimen>

```astro
<ChipGroup label="Model" options={[['anthropic', 'Anthropic'], ['openai', 'OpenAI']]} data-k="provider" />

<script>
  group.addEventListener('ui-change', (e) => use(e.detail.value))
</script>
```

## Summary

The first block of a guide, right under the title, the lead and the page actions: what the page is about, when you need it and what you write, so a hurried reader knows in ten seconds whether to stay. Values may hold `inline code` in backticks; `jump` adds a link to the example on the page. On a phone the label sits above its value.

<Specimen layout="col">

</Specimen>

## Masonry

A gallery of tiles of different heights that fills the free space: a short tile sits right under its neighbour, with no gap below it. The tiles read left to right, become one column on a phone, and re-pack when a tile grows (an image loads, a font arrives). Use it where tiles are independent specimens, as on [Blocks](../../frontend/blocks/). Keep a plain grid where tiles open in place (a code disclosure) or should line up as rows; a re-pack there moves tiles away from the reader.

<Specimen layout="col">
  <Masonry label="Tiles of any height" min="10rem">
    {[64, 120, 40, 96, 150, 56, 88, 72].map((h, i) => <div class="ui-tile ui-tile--sm" style={`height:${h + 40}px;font:600 var(--fg-fs-sub)/1 var(--sl-font-mono);color:var(--fg-ink-2)`}>{i + 1}</div>)}
  </Masonry>
</Specimen>

```mdx
import { Masonry } from '../../components/ui';

<Masonry label="Every block" min="15rem" gap="12px">
  <figure>…</figure>
  <figure>…</figure>
</Masonry>
```

`min` is a column's smallest width; `gap` is the space between tiles in both directions. Each direct child is a tile. A gallery built by script after load is packed with `masonry(el)` from `ui.ts`.

## Compare

Two to six items on one scale, as horizontal bars. Our row is drawn in the accent and the others are muted; each value sits at the end of its bar. `better` adds a small caption, `unit` names the scale and `note` cites the source. Bars scale to the largest value, or to `max` (say, 100 for percentages).

## Source list

The top-level places of a section, with the current one marked: the sidebar's topic switcher, like the source list in Finder, Mail and Notes. ## Search

Search works like Spotlight. A pill in the header (an icon on a phone) opens a sheet over the page, and **⌘K**, **Ctrl K** or **/** opens it from anywhere. Results come instantly from the site's index, grouped **Guides**, **Reference** and **Specs**, with the matched section after the page title.
- With nothing typed, the sheet shows recent and suggested pages.
- Whenever something is typed, the last row is **Ask AI** with that question, so a search with no match still has a next step. A site built without an assistant has no such row; instead, a search with no match suggests fewer or other words.
- From the keyboard: ↑ ↓ move, Return opens, ⌘ Return opens in a new tab, and Esc clears the field and then closes the sheet.
- On a phone the sheet fills the screen, with **Cancel** beside the field.

## Tokens

Use the tokens, never a raw colour, size or radius. The full scales are in the `ui-craft` skill (`references/tokens.md`); the docs' names:

| Token | For |
| --- | --- |
| `--fg-ink`, `--fg-ink-2`, `--fg-ink-3` | text: main, secondary, captions |
| `--fg-surface`, `--fg-sunken` | a tile, code inside a tile |
| `--fg-fill`, `--fg-fill-2` | chips, gray buttons, tracks; their hover |
| `--fg-accent`, `--fg-on-accent`, `--fg-accent-ink`, `--fg-accent-soft` | the one accent: fills, text on it, accent text, a tinted surface |
| `--fg-focus` | the focus ring (`:focus-visible` only) |
| `--fg-fs-caption` … `--fg-fs-title` | 11 · 12 · 13 · 15 · 17 · 22 px |
| `--fg-r-sm` … `--fg-r-pill` | 6 · 10 · 14 · 20 · 24 · 999 px |
| `--fg-h-sm`, `--fg-h-md`, `--fg-h-lg` | 32 · 36 · 44 px (all 44 on touch) |
| `--fg-dur-instant`, `--fg-dur-quick`, `--fg-ease` | 120 ms, 200 ms, the entering curve |
