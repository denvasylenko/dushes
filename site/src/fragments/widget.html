Configurable

  • attributes, chat.options = {...} or React props, applied live
  • mode: floating, inline, page; scheme: auto (live), light, dark; theme: default, contrast or your own from defineTheme (tokens per scheme and scoped CSS)
  • tokens: --agui-accent, --agui-radius, --agui-font…; parts: ::part(card)…
  • 7 languages, any string overridable

Extensible

  • chat.renderers.set(type, fn): your own card; resolve(value) resumes
  • chat.registerTool({...}): frontend tools that can render into the chat
  • chat.agent = new HttpAgent(...): any AG-UI agent object
  • events agui:event, agui:run-end…

Every option, token, method and the plugin API: docs/chat-widget.md. Try every switch live: the demo server's /examples/widget/.
